# Exporters troubleshooting

| Symptom | Likely cause | Fix |
|--------|--------------|-----|
| Crash on load | RAW size mismatch | Re-export RAW or switch to PNG |
| Flat/inverted terrain | Wrong flip settings | Toggle flips or re-export |
| Missing textures | Bad file path/name | Fix references |
| Blend not visible | Layer/channel mismatch | Correct layer count/channel |
| Low performance | Heavy grass or low LOD settings | Tune density and LOD |
