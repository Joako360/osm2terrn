# ADR-0009: Keep the Application Stateless

**Y-Statement**

In the context of building a deterministic and testable processing application, facing the complexity introduced by shared mutable state, we decided to keep the application stateless by passing explicit configuration and processing context to each component to achieve predictability, easier testing and safer parallel execution, accepting more explicit parameter passing.
