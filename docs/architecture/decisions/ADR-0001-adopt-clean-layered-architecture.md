# ADR-0001: Adopt a Clean Layered Architecture  
   
**Y-Statement**  
   
In the context of a growing geospatial map generation project, facing increasing coupling between user interfaces, business logic and infrastructure, we decided to adopt a clean layered architecture to achieve separation of concerns, maintainability and long-term scalability, accepting a larger number of modules and a more explicit project structure.
