# ADR-0002: Model the Domain Independently from External Frameworks

**Y-Statement**

In the context of integrating multiple geospatial libraries and data formats, facing the risk of coupling business rules to third-party APIs, we decided to model the domain independently from external frameworks to achieve portability, testability and long-term maintainability, accepting the need for explicit conversions between domain and infrastructure models.
