# ADR-0007: Design Exporters as Independent Plugins 
   
**Y-Statement**  
   
In the context of supporting different target simulators and output formats, facing the risk of embedding export logic throughout the application, we decided to design exporters as independent plugins to achieve extensibility and clear separation between processing and serialization, accepting additional extension points.
