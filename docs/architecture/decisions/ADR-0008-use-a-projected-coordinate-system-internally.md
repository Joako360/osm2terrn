# ADR-0008: Use a Projected Coordinate System for Internal Processing

**Y-Statement**

In the context of performing geometric operations on geographic data, facing the limitations of latitude and longitude coordinates for metric calculations, we decided to use a projected coordinate system internally to achieve numerical consistency and simpler spatial algorithms, accepting coordinate transformations at system boundaries.
