# ADR-0005: Preserve Geospatial Information Until Export

**Y-Statement**

In the context of generating maps for different simulation platforms, facing the temptation to transform source data directly into game-specific formats, we decided to preserve geospatial information in a platform-independent domain model until the export stage to achieve extensibility and data fidelity, accepting an additional transformation step.
