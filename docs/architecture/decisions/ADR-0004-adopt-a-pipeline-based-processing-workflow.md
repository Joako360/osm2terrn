# ADR-0004: Adopt a Pipeline-Based Processing Workflow
   
**Y-Statement**  
   
In the context of transforming geospatial data through multiple processing stages, facing increasingly complex processing logic, we decided to organize the application as a processing pipeline to achieve modularity, traceability and composability, accepting a more explicit execution flow.
