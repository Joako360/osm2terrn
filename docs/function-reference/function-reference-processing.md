# Function reference: processing and export

Current terrain processing is organized under `osm2terrn/processing/terrain/`,
roads under `processing/network/` and `processing/roads/`, with stage
coordination in `processing/orchestrator.py`. The previous flat module names
in this page were stale and have been removed.

Use the [architecture module map](../architecture/architecture-modules.md),
[export flow](../cli-flow/cli-export.md), and generated
[symbol inventory](../book/inventory/symbols.jsonl) for current locations.
Static inventory does not establish execution or product compatibility.
