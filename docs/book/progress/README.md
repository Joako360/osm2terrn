# Progress Records

- `coverage.md` summarizes the four independent record-level state axes and
  the current scope-wide progress.
- `inventory_report.md` is generated by
  `docs/book/inventory/inventory_tool.py validate --write-report`. Do not edit
  it manually; it reports static inventory counts, validation results,
  exclusions, unresolved reasons and analysis limitations.
- `decisions.md` records documentation and inventory-contract decisions.

Regenerate the inventory report from the repository root with:

```powershell
python docs/book/inventory/inventory_tool.py validate --write-report
```

A validation result does not show that the application or tests ran. Execution
evidence requires the exact command, test ID where applicable, environment,
result, inspected revision and observation date.
